# HSK1 Mock 01 audio drop zone

Thư mục này cố ý chưa chứa MP3. Hãy đặt 20 file âm thanh thật vào đây theo đúng tên:

`q01.mp3` … `q20.mp3`

Mỗi file tương ứng một câu nghe trong `docs/listening-script-per-question.md`. Không dùng file rỗng, file giả hoặc browser TTS để thay thế. Sau khi bổ sung audio, kiểm tra `docs/audio-assets.md` và cập nhật trạng thái `audioStatus` trong JSON nếu cần.
