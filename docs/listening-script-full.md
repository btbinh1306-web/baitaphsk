# Full production script – HSK 1 Mock 01

## Audio production contract

Produce exactly 20 independent MP3s. The filename is the stable question ID, not the array position. Every file follows this envelope:

`[silence 0.5s] → first read → [silence 1.5s] → second read → [silence 5s]`

The silence is part of the production cue and is not spoken. A human narrator may replace TTS, but the spoken Mandarin text must remain unchanged. Do not record answer letters or options.
