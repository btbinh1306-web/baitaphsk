# Bản xem trước bài tập HSK1 Bài 6–15

Đây là bản để duyệt nội dung, chưa được nối vào catalog web.

Mỗi đề có đủ 5 kỹ năng:

- nghe
- nói
- đọc
- viết
- dịch (Việt → Trung ghi âm, Việt → Trung viết, Trung → Việt viết)

Phần nghe hiện dùng kịch bản TTS ẩn trong dữ liệu; sau khi duyệt có thể thay bằng file audio thật. Các đáp án mẫu được để ngay dưới từng câu để kiểm tra nhanh.
