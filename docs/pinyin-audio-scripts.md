## Lưu ý câu 3

Đề gốc ghi đáp án `fò`, nhưng chữ `佛` đọc chuẩn là `fó`. Nếu vẫn giữ đáp án `fò`, file `pinyin_listen_1_03.mp3` cần đọc âm tiết **fò** riêng, không đọc chữ `佛`.
